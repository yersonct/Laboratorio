# Gobierno documental

> Estado: 🟡 En progreso | Última actualización: 2026-06-30

## Contexto

Este directorio reúne las políticas, estándares y lineamientos que regulan la documentación del proyecto. Su propósito es garantizar que todos los equipos documenten con el mismo criterio, mantengan la trazabilidad de los cambios y eviten la duplicidad de información o la publicación de datos sensibles.

## Objetivo

Este conjunto de documentos sirve como referencia para todos los integrantes del proyecto y establece un proceso común para crear, mantener y revisar la documentación técnica durante todo el ciclo de vida del desarrollo.
